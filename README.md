# TDD_e_BDD

TDD (Test-Driven Development)

O TDD é uma prática técnica focada na qualidade e arquitetura do código. O desenvolvedor escreve o teste unitário antes de criar a funcionalidade, Garante que o software seja construído sem bugs estruturais e de forma modular.

BDD (Behavior-Driven Development)

O BDD é uma prática colaborativa focada no comportamento do negócio e na experiência do usuário. Ele traduz requisitos de produto em cenários de teste usando linguagem natural estruturada (Dado/Quando/Então). Isso alinha a comunicação entre desenvolvedores, testadores (QAs) e gerentes de produto (POs) antes do código começar a ser escrito.
